# Правила работы с репозиторием

## Git

- Коммиты и отправку в GitHub пользователь выполняет сам, вручную.
- Не выполнять `git commit`, `git commit --amend` или `git push` и не создавать коммиты автоматически.
- Задача ассистента — подготовить изменения, запустить подходящие проверки и кратко сообщить, что готово к ручному коммиту.
- Не переписывать историю и не перемещать ветки без отдельной прямой просьбы пользователя.
- Автор пользователя — `paNikitin`. Не изменять глобальные настройки Git.

## Публичная заготовка

- В репозитории находятся только ученические файлы: заготовка, открытая среда, примеры, тесты и инструкции.
- Готовые решения и преподавательские материалы остаются за пределами репозитория; не переносить их в публичные файлы.
- Не добавлять в Git `.env`, токены, ключи, локальные настройки, кэши и виртуальное окружение.
- При подготовке чистой заготовки сначала сохранять рабочее решение пользователя отдельно, чтобы не потерять его работу.
